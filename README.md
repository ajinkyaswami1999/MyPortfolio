## 💻 Running This Portfolio Locally

This portfolio is built with [Next.js 16](https://nextjs.org/) (App Router & Turbopack) and [Tailwind CSS](https://tailwindcss.com/).

```bash
# 1. Clone the repository
git clone https://github.com/ajinkyaswami1999/MyPortfolio.git

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

```bash
# Run SEO & Canonical Audit
npm run seo:audit

# Build for Production
npm run build
```
